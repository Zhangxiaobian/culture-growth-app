# 每天长一点｜每日 7 天拆分课程版（精简导航版 · 护眼浅色版）

这次升级成了 **52 周 × 每周 7 天拆分** 的版本。

## 这次升级了什么
- ✅ 整体界面改成更柔和的 **护眼浅色风格**，减少暗底灰字带来的费眼问题
- ✅ 修复笔记保存后只留在文本框、不进入记录列表的问题：现在“记录”页会同时展示**笔记**和**打卡**
- ✅ 每一周都继续拆成 **7 天**
- ✅ 今天页不再只告诉你“本周学什么”，而是直接告诉你 **今天该学哪张卡、该回答什么问题、该做什么输出**
- ✅ 课程页可以展开看 **52 周完整课程 + 每周 7 天安排**
- ✅ 保留打卡、笔记、导入导出、开始日期等核心功能
- ✅ 继续适合部署到 GitHub Pages、静态站点、PHP 网站目录

## 现在首页会看到什么
- **本周主题 / 本周目标**
- **第几天的拆分重点**
- **今日必学卡片**
- **今日理解要点**
- **今日小自测**
- **今天这一小时怎么学**
- **今日输出与本周结果**
- **笔记与打卡**

## 文件说明
- `index.html`：主应用
- `manifest.webmanifest`：PWA 清单
- `sw.js`：离线缓存 Service Worker
- `icons/`：应用图标
- `一年成长计划.md`：52 周文字版课程（含 7 天拆分）
- `README.md`：当前说明
- `culture_growth_app.zip`：打包版本（位于当前会话根目录）

## 数据保存方式
- 默认保存到浏览器本地 `localStorage`
- 可导出为 JSON 备份
- 换设备或换浏览器时可导入恢复

## 如果你已经部署到 GitHub Pages
请把更新后的文件重新覆盖到仓库里并重新提交，至少包括：
- `index.html`
- `README.md`
- `一年成长计划.md`
- `sw.js`

## 一句话
这次的重点不是“周主题”，而是“每天打开就知道今天具体学什么”。
