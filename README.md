# 每天长一点｜52 周课程版

这次不是只有打卡壳子，而是把 **52 周真正要学的内容** 放进 App 里了。

## 这版重点变化
- ✅ 每一周都有 **导学 + 核心知识卡片 + 自测题 + 输出任务**
- ✅ 删除了页面里的安装指导、安装帮助等干扰内容
- ✅ 保留打卡、笔记、导出、导入、开始日期等核心功能
- ✅ 适合继续放在 GitHub Pages、静态站点、PHP 网站目录中使用

## 你现在能在 App 里看到什么
- **今天**：当前周的目标、导学、今天这一小时该怎么学、本周核心知识卡片、自测题、本周输出
- **课程**：52 周完整课程总览，每周都能展开看实质内容
- **记录**：打卡热力图、成长徽章、最近记录
- **设置**：开始日期、数据导入导出、重置、文字版资料

## 数据保存方式
- 默认保存到浏览器本地 `localStorage`
- 可以导出为 JSON 备份
- 换设备或换浏览器时可以导入恢复

## 如果你已经部署到 GitHub Pages
这次改动属于 **内容升级**。如果你线上还是旧版本，需要把更新后的这些文件重新覆盖到你的仓库里并重新提交：
- `culture-growth-app/index.html`
- `culture-growth-app/README.md`
- `culture-growth-app/一年成长计划.md`
- `culture-growth-app/sw.js`
- `culture_growth_app.zip`
