# 每天长一点｜文化成长打卡 App（安装优化版）

这是一个更像手机应用的 **PWA 版本**。这一版重点补强了“为什么没有弹出安装提示”和“不同手机怎么装”的问题。

## 这次又新增了什么
- ✅ 新增 **PNG 安装图标**（192 / 512 / Apple Touch Icon），提高安卓与 iPhone 识别率
- ✅ 新增 **安装环境检测**：自动告诉你现在是不是 `file://`、是不是可安装环境
- ✅ 新增 **Android / iPhone / file 模式 / 内置浏览器** 的分场景安装说明
- ✅ 新增顶部 **“安装帮助”** 按钮
- ✅ 优化安装按钮文案：会根据你当前设备显示不同提示
- ✅ 更新离线缓存资源，包含新的图标资源

## 文件说明
- `index.html`：主应用
- `manifest.webmanifest`：PWA 清单文件
- `sw.js`：离线缓存 Service Worker
- `icons/`：应用图标（SVG + PNG）
- `一年成长计划.md`：全年成长计划文字版
- `README.md`：使用说明
- `culture_growth_app.zip`：打包版本（位于当前会话根目录）

## 为什么“直接打开 HTML”通常不弹安装
如果你是直接双击 `index.html`，地址一般会是：
- `file:///.../culture-growth-app/index.html`

这种方式下：
- 打卡、笔记、导出通常能用
- 但 **安装到主屏幕**、**离线缓存**、**完整 PWA 能力** 往往不会正常触发

所以如果你要真正装到手机桌面，建议改成：
- `https://你的域名/culture-growth-app/index.html`
- 或 `http://localhost/...`

## 安卓怎么安装
推荐浏览器：**Chrome / Edge**

步骤：
1. 用 Chrome 或 Edge 打开网址
2. 等页面加载几秒
3. 点击页面顶部“安装到手机”
4. 如果浏览器没有弹窗，再去浏览器菜单中找：
   - **安装应用**
   - 或 **添加到主屏幕**

## iPhone 怎么安装
推荐浏览器：**Safari**

步骤：
1. 用 Safari 打开网址
2. 点击“分享”按钮
3. 选择 **添加到主屏幕**
4. 确认添加

> 注意：iPhone 上很多时候 **不会自动弹出安装窗口**，这是正常现象，不代表你的 App 有问题。

## 哪些情况会导致安装失败
### 1）直接双击本地 HTML
也就是 `file://` 打开。最常见。

### 2）在微信 / QQ 内置浏览器里打开
很多内置浏览器不支持安装。

### 3）浏览器本身不主动弹窗
即使条件满足，也可能需要你手动去浏览器菜单里安装。

## 最推荐的使用方式
1. 把整个 `culture-growth-app` 文件夹放到你的网站目录、宝塔站点或 localhost
2. 用手机浏览器打开 `index.html`
3. 点击“安装到手机”或“添加到主屏幕”
4. 以后直接从桌面打开打卡

## 一句话
这一版重点不是“更花哨”，而是让你 **更容易知道为什么装不上，以及下一步该怎么装上**。
